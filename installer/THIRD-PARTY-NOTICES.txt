Recommended, not included: Splash Damage script by Stevey666
  Download it yourself from https://www.digitalcombatsimulator.com/en/files/3344761/
  Warclock embeds an unchanged copy into generated missions if you place Splash_Damage_*.lua
  into %LOCALAPPDATA%\DCS-Kampagne\scripts (setup task "Splash Damage"). It remains the work
  of its author; credit and support via the DCS forum thread.

  DCS-ATC is a separate project (GPL 3.0, https://github.com/Iceman1991/DCS-ATC-Release).
  It is not part of this setup; Warclock downloads its latest release on first start
  only if the option was ticked. Its own notices ship with it.
